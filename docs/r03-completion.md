## 1. 结论

R03 在已声明的研究范围内完成结项。结项含义是：所有分工均有版本化交付；已知因素有来源映射和唯一 ID；Q/O/D/L 已逐项填写，或在证据不足／指标不适用时给出可审计的不可评估理由、适用边界和回退动作；组合敏感性和复算入口已登记。

“因素级 L 未识别”是本轮的研究结论，不是遗漏：现有策略级留出把额度、余量、窗口和成本共同改变，无法在同一输入下识别单因素省略的闭环损失；将共同收益拆给单因素会违反 MET-01 的归因条件。因此 R03 不宣称任何未完成消融的因素可忽略，也不把策略级收益误称为单因素 L。

## 3. 新增或复核证据

- 合成固定边界干预 864 条，复算与归档逐行一致；预算局部异号 `56/144`，共享 `3/288`，到达时刻 `13/96`。
- 100 组未到达场景审计：相同可见状态下确定性最坏遗憾下界 `3.060135 ms`，两动作随机化最小最坏期望遗憾 `1.882647 ms`。
- 480 配置 CPU 留出复算；报告策略级零开销／含决策开销／P95／最大单请求退化，不拆分归因。
- 因素组合审计：预算×共享、预算×到达、共享×到达均出现混合符号组；成本倍率相关组合在当前固定基线口径下无合格组，标为不可估计而非零影响。
- 任务成本记录：合成干预约 0.8 s，汇总约 0.06 s，R02 验证约 1.8 s，480 配置留出约 76.7 s；这些是本机复算成本，不是跨硬件或人员工时承诺。

组合审计见 `docs/evidence/r03-app01-interactions.json`；成本记录见 `docs/evidence/r03-task-costs.json` 和 `docs/evidence/r03-task-costs-holdout.json`。

## 4. 适用边界与保留事项

1. CPU 模拟的 D/L 和成本只说明模型内恢复边界行为，不能直接解释真实 TTFT、TPOT、吞吐、SLO 或服务发生率。
2. GPU 侧 F06、F08、F09、F12、F13 的真实活动状态和残余时间仍受观测限制；O 评级已保留为 O2 或相应未知，不用 CPU 结论替代。
3. F15 的未来到达、事后完成时间和离线标签仅作为评价／下界，不得作为在线输入。
4. F16 的多通道、持久驻留、时变带宽和连续批处理不属于本阶段执行语义；后续如研究，必须另立范围和遗漏预算。
5. 因素级 L、组合留出和投入成本仍可作为后续深化任务，但不再是 R03/v1.0 在当前证据范围内的隐藏未交付项；若要把“不可识别”改为数值 L，必须新增同输入消融实验并建立新版本。

## 6. 因素级 L 补充结论

本轮新增 144 个同输入闭环消融，已把 F08、F09、F10、F11、F13 从“完全未识别”推进到“CPU 合成子域内可量化”。F08/F10 当前共享同一覆盖窗口字段，不能在现有实现中再拆成独立贡献；F09 的零损失是因为该合成域没有活动在途状态，不是对真实服务的忽略许可；F11 是当前子域中影响最大的可消融成本因素。

因此后续重点从“是否存在任何证据”转为“公开轨迹／真实状态的域外验证”。若没有新的活动在途或独立窗口状态，继续在当前合成夹具上细分将属于重复实验，不再投入。
