## 4. 缺口、验收和回退

- **Q/D/L 缺口**：待 APP-01 提交后按相同 ID、分母、适用域、基线和留出边界填入；不能用已有异号组直接代替闭环 D/L。
- **GPU 状态缺口**：F06、F08、F09、F12、F13 的硬件侧在线状态仍有限；CPU 结论不得外推真实服务性能。
- **净开销缺口**：所有前瞻、证书、查询、回退和剩余推演开销要与零开销策略质量分开，最终报告平均响应、P95、最大单请求退化和净收益。
- **组合缺口**：单因素结果不能推出联合安全；至少覆盖容量×余量、共享×释放、在途×同刻、代理×成本误差等组合。
- **回退规则**：状态区间跨候选平局、违反合法性／信息约束、观测不可用或净收益未证实时，回退冻结完整求值／`local-cost` 基线，不新增策略。
