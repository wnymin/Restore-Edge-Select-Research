# 第一阶段实验约定

目标是比较恢复边界策略。请求在首次进入预取窗口时选择一次边界，之后不改选；所有策略共用固定的缓存放置、可恢复检查点、计算服务顺序和传输规则。

边界 `c>0` 需要截至 `c` 的所有全量注意力 KV，以及在 `c` 的一份循环状态和卷积历史。依赖就绪后从 `c+1` 续算；`c=0` 从头重算；`c=L` 且依赖就绪时，在交接后即完成预填充。初始共享缓存只读，重算结果不写回。主场景中 KV 在 RAM，循环检查点在 SSD，两条路径共用显存预取额度。

按到达顺序服务，同时只计算一个请求；同时到达时按轨迹顺序。预取窗口包含当前请求及其后固定数量的已到达请求。尚缺依赖一次预留显存，已加载对象留在预算中直到交接；放不下的候选仍可在队首按需加载。传输队列串行，当前请求按需传输优先，已发出的传输不抢占，可与计算重叠。在途对象由当前请求接管，避免重复加载。共享只读对象按标识去重；循环状态独占时可原位接管，否则为续算创建可写副本。

模型和固定开销、执行空间、预取空间合计不超过设备显存。固定执行预算后再扫描预取额度，并保证每条请求从头重算均可执行。各路径按启动延迟加字节数除以有效带宽估算；后缀重算采用 `a*(L-c)+b*(L*(L+1)-c*(c+1))/2`。时间线计算排队和重叠。首条验收轨迹使用合成成本；正式硬件参数需另行校准或做区间分析。

比较全重算、最长可行边界、固定阈值、逐请求最低成本和小规模离线穷举。主指标为到达至预填充完成的平均时间；记录峰值预取字节、等待、传输量和重算量。模拟结果不等于实测 TTFT。
