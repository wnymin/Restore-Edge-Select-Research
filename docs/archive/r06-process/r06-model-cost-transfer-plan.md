# R06 模型与成本适用域验证

- **状态：** 2026-11-20 拟定、启动并完成 CPU 范围验收。以下任务由我方负责，暂不拆分协作。
- **目标：** 验证 R05 的「快速选点＋完整搜索回退」能否迁移到不同模型参数与成本条件，区分可复用的门控、必须重校准的阈值，以及应禁用快速路径的工况。
- **范围：** 只放宽模型参数与成本域。固定请求顺序、到达窗口设计、缓存放置规则、精确检查点恢复、单计算槽、串行传输和共享预取额度。不改变到达机制，不引入多通道、批处理或端到端 GPU 验证。后续顺序以[统一研究协议](../../recovery-research-protocol.md#放宽假设的研究顺序)为准。

R05 留出结果中，`portfolio-v4` 优于 `entry`，但未超过 `entry-replay`。R06 不把回放实现的加速归因给门控。即使没有可迁移的正收益，找出失效条件、复现反例并给出回退范围仍是有效的研究交付，但不能称为算法通过性能验收。
