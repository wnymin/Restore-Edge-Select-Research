# R06 模型与成本适用域预登记

2026-11-20 冻结，负责人为我方。矩阵与输入哈希见 [运行配置](../../../configs/r06-matrix.json)。

- 使用本地归档 Qwen3.5-4B 与由其构造的 GQA/GDN 模型。合成模型保留 8 层 GQA、24 层 GDN 和卷积历史，将 KV 头数从 4 改为 8、GDN 的 V 头数从 32 改为 16。载荷为每 token 65,536 B、每检查点 26,050,560 B。按各层完整 KV 和边界检查点构建依赖并由执行器验证。续算网格的比例缩放和传输成本倍率均为模拟干预。
- 沿用 Trace B 的每窗 256 条历史、最多 96 条评测、输入上限 3,584、间隔 1/4、RAM／SSD／混合检查点放置和 128／384 MiB 共享预取额度。校准用 200–202，确认性留出用 400–411。校准先在原模型和 SSD 11 倍锚点分别改变 KV、检查点、续算、RAM、SSD，再跑两模型的 1／11／32 倍 SSD 组；留出两模型分别跑低、中、高三组，使用独立的（续算、RAM、SSD）组合 `(1, 3/2, 3)`、`(3/4, 2, 13)`、`(5/4, 3, 24)`。所有放置和额度与上述因素成对交叉。传输倍率同时缩放启动延迟与每字节耗时。
- 保留 `local-cost`、`entry`、`entry-replay`、原样 `portfolio-v4`。按模型和放置校准旧门控的 SSD 阈值，选取校准中允许的最大阈值 `0/1/11/32`，0 表示关闭。阈值必须满足观察到的目标损失预算，且覆盖至少一个压力档。先冻结阈值和统一规则，再打开留出。
- 统一门控使用决策时可见的续算及复制成本、增量传输和可覆盖工作。竞争、共享、容量临界或近似平局时回退原 `entry-replay` 路径。统一相对裕量候选为 `0/1%/5%`，在校准上选满足零开销预算且跳过次数最多者，平局取较大裕量。
- 对照在相同输入上做确定性零开销回放和注入本机选点耗时的闭环回放。每配置各策略预热一次，六个计时轮次采用随机初始顺序及循环轮换，使各策略各占一次每个执行位置。每配置取逐轮配对差的中位数，按窗口聚合，并以窗口为簇做 10,000 次固定种子 bootstrap。三个候选分别按模型及成本组报告。各组以双侧 95% 区间下端大于零为支持正净收益的证据，结论限于模拟组，区间未进行组间多重比较校正。
- 相对 `entry-replay` 的每配置零开销均值损失上限 0.1 ms，单请求上限 1 ms。计入决策开销后，每配置配对 P95 损失中位数上限 1 ms，所有计时轮次的最大单请求损失上限 10 ms。门槛为预登记的模拟研究容忍量。报告动作变化、回退、零开销和含开销损失、决策时间与窗口级不确定性。若某组预算或净收益条件失败，保留 `entry-replay`。带宽倍率仅为成本模型输入。
