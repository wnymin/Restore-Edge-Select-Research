# R03 已知未完备因素的难度闭合记录

- **版本**：`R03/v1.0-factor-closure`
- **日期**：2026-11-19
- **目的**：对 R03 中仍未获得普通数值 L 的因素逐项判断：继续实验、不可用普通 L 表示，或在当前范围内难度过大而停止。

## 判断规则

只有在当前固定语义下存在合法的“同输入、同快照、同候选、同成本、同执行器、保留／省略因素”对照，才继续计算因素级 L。若省略会改变合法动作集合、违反在线信息约束，或所需状态只能从真实 GPU 事后真值获得，则不把伪造的零值或平均策略收益当作 L。

## 闭合结果

| 因素 | 当前状态 | 为什么不能继续按普通 L 处理 | R03 决定 |
| --- | --- | --- | --- |
| F01 合法依赖 | 硬约束 | 删除依赖检查会产生非法候选，不是性能消融 | 保留约束，不做标量 L |
| F02 已到达请求／队首 | 信息约束 | 未来到达不可在线；已有相同可见状态的信息下界 | 用信息下界结论闭合；不伪造在线 L |
| F03 预留／剩余额度 | 可行性约束 | 省略额度会改变候选能否合法准入；不能用平均损失豁免 | 保留容量状态；局部 D 已完成，普通 L 不适用 |
| F04 共享身份／去重 | 状态定义 | 改变共享身份同时改变对象图、计费和复制语义，不是单字段删除 | 保留对象身份；已有共享 D，继续拆分需新语义 |
| F05 释放／交接／重试 | 执行器事件语义 | 省略会改变事件顺序和队首路径，等同修改执行器 | 以 R02 机制反例闭合；不做伪 L |
| F06 就绪／在途身份 | 可行性状态 | 删除状态会允许使用尚未就绪对象，违反恢复语义 | CPU 精确保留；GPU 侧转为真实状态验证任务 |
| F07 搬运次序／同刻规则 | 执行器语义 | 改变次序本身就是另一个执行器，不是因素省略 | 以顺序反事实证据闭合；不做普通 L |
| F08 运行余量／覆盖窗口 | 已完成 CPU 子域消融 | 144 配置同输入消融已得 36.81% 动作变化和平均 1.3012 ms L | 当前 CPU 子域完成；公开轨迹留出后置 |
| F09 在途残余／有效就绪延迟 | 当前合成域不可识别 | 合成夹具没有活动在途；真实残余需 GPU 观测分布 | 记录 0/144 仅代表无样本；当前 CPU 继续实验停止 |
| F10 可覆盖搬运量／消费窗口 | 与 F08 字段耦合 | 当前实现中与覆盖余量共享字段，无法合法拆分独立贡献 | 合并解释；独立拆分需重构状态模型 |
| F11 成本差 | 已完成 CPU 子域消融 | 144 配置同输入消融得到 69.44% 动作变化、平均 9.0766 ms L | 当前 CPU 子域完成；真实成本校准另立验证 |
| F12 状态／成本误差 | 证据需求过高 | 需要真实误差分布或预注册误差模型，事后真值不能在线回填 | 当前范围停止；保留区间和回退 |
| F13 同行竞争代理 | 已完成 CPU 子域消融 | 144 配置同输入消融得到 35.42% 动作变化、平均 1.2502 ms L | 当前 CPU 子域完成；公开多请求留出后置 |
| F14 近似平局／邻域 | 评价分层，不是独立输入 | 它用于放大敏感性和分层，不能单独做在线省略 | 贯穿已有消融；不单独定义 L |
| F15 未来／事后信息 | 禁止在线输入 | 使用它会违反信息约束 | 仅作离线真值和下界 |
| F16 模型外执行语义 | 当前范围外 | 没有冻结多通道／批处理语义和遗漏预算 | 停止，另立后续研究版本 |

## 停止条件

在当前阶段继续构造 F09、F12 的 CPU 合成样本不会增加真实可识别性；继续拆分 F08/F10 会重复同一字段；对 F01–F07、F14–F16 强行做普通 L 会违反指标定义或研究范围。因此这些方向按“当前范围内难度过大／指标不适用”停止，不称为低影响，也不称为真实服务已验证。

若后续获得新的状态接口、真实活动在途样本、独立覆盖窗口建模或多通道执行语义，应建立 `R04-*` 或新的 R03 版本，而不是修改 R03/v1.0 的结论。
