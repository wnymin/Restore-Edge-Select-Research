## 1. 评估口径

本任务只回答“当前恢复边界算法在决策时能否获得并使用该因素”。不把事后完成时间、离线最优标签或未来到达请求回填为在线输入；不把 CPU 模拟可读取的精确状态外推为 GPU 或真实服务已可读取；不把缺少测量证据强判为 `O3`，证据不足使用 `OU` 或分域说明。

当前决策点是首次入窗、候选边界已经生成之后、候选搬运入队之前。固定语义为单计算槽、串行传输、共享 HBM 预取额度、非抢占搬运、首次入窗只选一次。CPU 模拟和 GPU 观测分别评级；跨域差异不得合并成一个更乐观的等级。

## 3. 信号、时点与开销登记

| 信号族 | 最早可用时点 | 当前利用 | 采集开销 | 决策开销 | 限制 |
| --- | --- | --- | --- | --- | --- |
| 候选依赖、对象身份、放置 | 候选生成／决策前 | 合法性检查、去重、缺失集合 | CPU 元数据读取；未单独计时 | 依赖遍历、并集计算；随对象／引用数增长 | 属于可行性约束，不适用平均损失豁免 |
| 到达前缀、队首、固定顺序 | 每次事件处理／入窗前 | 只处理已到达前缀和当前队首 | 事件队列读取 | 常数级队列扫描，具体开销未单独拆分 | 未来到达禁止使用 |
| 额度、预留、释放、重试 | 候选准入／事件转移前 | 计算新增预留、释放后重试和按需加载 | CPU 快照可读；未单独计时 | 并集扫描和候选比较，未独立计时 | 失败准入不等于不可执行 |
| ready／in-flight／传输顺序 | 每次决策前 | CPU 使用精确状态；GPU 仅有限查询 | GPU 查询中位数约 1.20–1.30 μs，最大约 14.0 μs（R02 7941） | 查询本身和剩余推演开销未形成完整净成本 | `pending` 语义不充分 |
| 运行余量、消费窗口、后继覆盖 | 决策前可见窗口 | CPU 前瞻求值；必要时回退完整策略 | CPU 推演开销有配对记录，但非 TTFT | 可随候选和后继数量增长 | 不能读取未来请求 |
| 成本模型 | 配置／候选生成时 | `local-cost`、`entry` 和路径成本 | 配置读取；校准误差未完全测量 | 成本累加和候选排序 | 真实活动期误差仍需评估 |
| 事后完成时间、未来到达、离线标签 | 决策后／尚未发生 | 仅离线评价 | 不计为在线采集 | 不允许进入决策 | 只能作真值或误差解释 |

R02 GPU 查询成本只能说明观测操作的局部开销，不能推出真实服务整体加速；CPU 决策计时也不能称为 TTFT、TPOT、吞吐或 SLO 实测。

## 4. 当前结论与回退

1. F01–F07 是可行性、容量或执行器状态，CPU 路径基本可直接取得；它们不能因为平均损失较小而删除。
2. F08–F11 在 CPU 模拟中具备可用路径，但其中 F09/F10 需要前瞻推演，必须把决策／证书／回退成本计入净收益评估。
3. F09、F12、F13 在 GPU 或真实服务侧只有代理、区间或有限状态；若区间跨候选平局或个体预算，当前安全动作是保留完整求值或回退冻结基线。
4. F14 是当前可计算的敏感性分层，不是可直接读取的“生产概率”；应报告 D/L，而不能将近似平局率解释为部署发生率。
5. F15 和 F16 不进入当前在线策略：前者违反信息约束，后者尚未冻结模型扩展语义。

本任务没有新增在线策略，也没有把任何因素宣布为全适用域可忽略。若后续 APP-01 证明某因素在声明子域内满足零动作差、零模型内完成差和留出条件，INT 任务仍需保留其适用域、损失预算与回退动作。
