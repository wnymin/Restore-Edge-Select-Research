# R03-MET-01：动态因素衡量模型与预注册

- **任务**：R03-MET-01
- **冻结版本**：v1.0
- **冻结日期**：2026-11-19
- **状态**：方法已冻结，供 R03-INV-01、R03-APP-01、R03-APP-02 使用
- **范围**：精确检查点恢复、Qwen3.5-4B 第一版 CPU 元数据模拟、现有在线算法与已有 GPU 观测
- **不在范围**：淘汰策略、活动 KV 分配、近似恢复、调度器重写，以及将 CPU 模拟时间解释为 TTFT/TPOT/吞吐/SLO 实测

本文件把“量化难度”“在线可用性”和“影响”分开冻结。未完成的实验不得填入猜测值；缺证据时使用 `OU` 或“未评估”，而不是将缺证据解释成低影响。

## 1. 固定语义与比较单位

每条样本必须固定以下内容：请求输入与到达顺序、缓存放置、合法候选边界、恢复检查点语义、同一成本配置、同一执行器事件规则、同一随机种子（若有）、比较时刻和目标函数。候选边界只表示完成边界前已处理的 token；非零边界必须具备完整前缀 KV、循环状态和卷积历史，边界 `0` 表示从头重算。

默认执行语义为单计算槽、串行传输、RAM→HBM 与 SSD→HBM 共用 HBM 预取额度、首次入窗只选一次、预取失败不等于候选不可执行，队首仍可按需加载。放宽任一假设时，必须记录失效位置并另做配对验证。

影响实验的基本单位是“同一输入／快照／候选／成本／执行器的保留与省略或扰动配对”。同一轨迹的多组干预不是独立生产样本，构造例只证明机制可能性。

## 2. 离线量化难度 Q

Q 只描述在拥有完整离线状态、全轨迹和事后真值时，因素能否形成可操作表示；不计在线采集开销。

| 等级 | 操作定义 | 可接受证据 |
| --- | --- | --- |
| `Q0` | 在声明适用域内可由离线状态直接确定；允许连续值、区间、事件类别、对象身份和顺序等离散结构，单位及时点明确，可进入反事实推演。 | 可由快照／事件记录重建，复算结果与原执行器一致。 |
| `Q1` | 只能表示部分状态、代理、区间或工况；缺失维度或误差可描述，能支持部分案例但不能普遍精确推演。 | 明确缺失维度、误差范围和适用工况，并能复算部分样本。 |
| `Q2` | 即使具备全局离线资料，也无法形成可操作表示，或表示会导致结论不可辨识。 | 必须指出数据、定义或识别障碍；“尚未做实验”不能单独判为 Q2。 |

## 3. 在线衡量难度 O

O 按当前算法和决策时点评分，不评价一个未来可能实现的遥测系统。每项同时记录：信号来源、最早可用时点、采集成本、决策成本、已利用部分、明确不可利用部分和未知项。

| 等级 | 操作定义 |
| --- | --- |
| `O0` | 决策前可直接获得，且当前算法完整利用。 |
| `O1` | 决策前可获得，但当前仅部分利用，或存在已知粒度／采集／计算开销限制。 |
| `O2` | 只能取得代理、区间或特定工况信号；关键部分不能用于当前决策。 |
| `O3` | 当前没有可用的决策前观测或算法路径。 |
| `OU` | 证据不足，暂不能定级；不得强行改判为 `O3`。 |

未来未到达请求、事后完成时间、离线最优标签不得作为在线输入；可用于离线评价和误差分析。

## 4. 影响指标 I

### 4.1 决策敏感度 D

在配对干预中定义：

$$
D = \frac{N_{\mathrm{changed}}}{N_{\mathrm{eligible}}}
$$

其中 `N_changed` 是因素保留与省略／扰动后发生任一决策变化的配对数；`N_eligible` 是满足输入、快照、候选、成本和执行器完全一致且完成合法比较的配对数。每项必须另外报告：

- 边界变化比例；
- 排序变化比例；
- 平局状态变化比例；
- 合法动作集合变化比例；
- 分母、排除原因和不确定区间。

D 不是生产发生率，不代表全轨迹或真实服务中的发生概率。若零样本，报告 `0 / N`，不能写成“因素无影响”。

### 4.2 基线劣化 L

对每个目标分别计算因素省略相对冻结基线的差值，保持方向明确：

$$
\Delta \bar{T} = \overline{T_{omit} - T_{base}}, \qquad
\Delta T_{95} = P95(T_{omit}) - P95(T_{base})
$$

必须报告平均响应差（ms 和比例）、P95 差、最大单请求退化、单请求改善／退化分布，以及计入决策、证书、采集、剩余推演和回退后的闭环净差。与离线最优的差单列；离线最优未认证时报告区间或下界，不伪装成精确值。

D 与 L 不合并为总分。优先级用二维表展示 `(D/L) × (Q/O)`；若确需总排序，必须列出权重并做权重敏感性分析，不预设统一权重或统一损失门槛。

## 5. 样本分层、配对和留出

每次实验至少记录以下分层：普通工况、容量临界、事件同刻及两侧单边邻域、共享／在途交接、候选近似平局、单请求与多请求、因素组合。设计集用于方法选择，留出集用于最终报告；窗口、种子、成本工况和过滤规则须在运行前冻结。

固定边界的单因素干预用于识别机制；闭环留出用于评估整体损失。单因素结果不能证明因素组合安全，必须对高影响候选做组合检查。完整策略作为闭环损失参照，`local-cost` 或已登记基线作为收益参照。

精确简化的最低验收标准是在声明子域内：动作不变（包括平局处理）且模型内逐请求完成向量不变。若研究近似简化，必须事先声明损失预算，并同时检查平均值、P95、最大单请求退化和可行性／信息约束；平均损失小不能豁免硬约束。

## 6. 每因素记录模板

| 字段 | 要求 |
| --- | --- |
| `factor_id` | 唯一、稳定，不因协作分工改变。 |
| `mechanism` | 说明因素如何影响合法性、关键路径或候选排序。 |
| `Q` / `O` | 按本文件等级填写；证据不足填 `OU` 或未评估。 |
| `source` | 文件、章节、证据文件或脚本入口。 |
| `unit` / `time_semantics` | 例如 bytes、ms、对象 ID、事件序号；说明快照时点。 |
| `online_signal` | 决策前可见内容；明确禁止使用的事后／未来信息。 |
| `collection_cost` / `decision_cost` | 已测填数值和单位，未测填 unknown。 |
| `D` / `L` | 含分母、适用域、基线、留出集和不确定性。 |
| `feasibility_constraint` | 是否为硬约束；硬约束不能用平均损失忽略。 |
| `omission_budget` / `fallback` | 省略前的预算、回退动作和触发条件。 |
| `evidence_status` | 已证、部分证、未知或待补证。 |

## 7. 判例与边界

- 候选依赖缺失、未来请求不可见、对象身份或同刻规则无法满足时，是信息／可行性约束，不因平均 L 较小而豁免。
- “预取失败”不等于“候选不可执行”；应保留队首按需加载路径并分别计成本。
- 共享对象必须按对象身份去重；共享布局的低翻转样本数不能直接证明可忽略。
- 活动残余和有效就绪延迟若只能事后获得，不能将事后真值回填为在线特征；保留区间、分支或回退。
- `entry-replay` 只优化固定边界推演，不改变边界选择策略。
