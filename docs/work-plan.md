# 双人研究分工

共同问题：**有限显存暂存容量下，怎样选取和使用混合模型的精确恢复边界，才能降低真实推理等待？** 两人分别拥有一条完整证据链：真实服务里有什么值得优化，以及这样的收益在哪些负载里出现、能否用在线信号识别。跑数、出图和初查可以由 agent 执行；负责人决定哪些解释值得竞争、哪些对照能排除它们、什么时候应该停止追一个方向。

现有[CPU 研究](boundary-findings.md)发现，常规成本下复杂选点未稳定胜过逐请求的 `local-cost`，拥堵时则存在排序翻转和跨请求代价。[真实服务](gpu-boundary-restore.md)已看到长前缀差的恢复收益，也看到短前缀差下目标与同行受益方向相反。两边都从这些结果继续，旧窗口用于复现和提出假设。[队列剪枝](boundary-findings.md#实现附节入口下界筛除)保留为实现优化。

## A：真实推理机制与系统优化（有 GPU 的成员）

**研究问题：从本来就快的驻留续算或按需恢复出发，哪部分关键路径还能缩短，代价是什么？**

- 负责真实服务的恢复成本模型与因果解释。区分排队、读盘、上传、续算和批处理时机。用跨场景配对判断收益主要来自少算 token，还是提前搬运、改变批次，或把等待转给了别人。场景按区分这些解释的能力选择，可用短差／长差、RAM／SSD、同行阶段和不同暂存压力做对照。
- 负责决定主系统方案。先与经过校准的逐请求选点和引擎可用的按需恢复做强对照，再根据瓶颈从提前暂存、精确增量恢复等候选中挑一个深入。比较相同显存预算与初始状态，检查循环状态和 KV 的恢复语义。若引擎不能实现某条路径，单列其上界并验证能真实运行的方案。
- 负责实测上能主张什么：先看目标首 token 延迟及整组完工，再在样本与连续负载足够时看 P95 和吞吐。远程卡可用于验证代表性正例和反例；大模型与换卡结论分开。远程资源不是结题前置条件。

**交付：**恢复路径实证与瓶颈解释、一个可运行的改进方案或经对照否证的方案、代表性正例和反例、精简数据和图，以及论文里的系统设计与实测章节。

## B：跨负载规律与在线策略（无 GPU 的成员）

**研究问题：什么负载和成本组合有可利用的改进空间，在线策略能否认出这些组合并避开退化？**

- 负责整个 CPU 研究体系：百炼轨迹与构造反例、模拟器的对照正确性、跨场景实验矩阵。把请求可观测特征转成有机制含义的量：额外复用所省续算、不能被覆盖的搬运、有限暂存造成的占用或等待。先用控制实验拆分，再看因素交互。明确到达与前缀复用来自何处、放置与候选如何构造，避免把人为压力点的命中比例当成生产频率。
- 负责形成跨场景判断。区分“逐请求已接近最优”“收益被排队或容量吞掉”“存在可被在线信号识别的机会”三类起点，由证据调整分类。用小规模穷举和同快照比较回答**有多少改进空间**，用闭环、不曾用于改规则的留出负载回答**实际策略拿得到多少**。对敏感的边界做反事实，区分成本不准、信号太晚和未来负载不可见。
- 负责在线选点或回退规则。可从现有 `local-cost` 与队列方案中选用或简化，保留同一候选、放置和预算。若动态方案只能在极端或窄区间获益，给出可识别的适用范围和默认基线。改变模型状态比例、续算成本和传输场景，报告结论在哪些条件下失效；离线外推作为敏感性证据。

**交付：**可复现的实验矩阵和模拟基线、负载分类与适用区间、在线规则和留出验证（或足以否定复杂规则的证据）、解释翻转或退化的反例，以及论文里的问题建模、策略设计和跨负载分析章节。B 用归档输入独立起步，负责决定 CPU 主线下一轮研究什么。

## 合并口径与决策节点

| 决策节点 | 两人的交接与共同判断 |
| --- | --- |
| 定义问题 | 共同固定精确恢复语义、候选与强基线，登记留出与有实际意义的改善幅度。两条线可以有不同的实验范围，但共同案例必须说明边界、放置、显存额度、并发和指标的映射。 |
| 淘汰解释、确定下一轮 | A 给 B 一组可用成本范围及无法分离的项；B 给 A 可区分竞争解释的少量场景，至少包含一个预测获益和一个预测退化的案例。出现实测与模拟不符，优先定位搬运、批处理或输入抽象的偏差；保留原预测，再改模型。 |
| 确认贡献、合并报告 | 在可实现的共同案例里，分别比较只换选点、只换恢复路径、两者都换；共享相同的参照路径和基线。区分模拟预填充完成、真实首 token 和生产外推。只有实际服务对强基线出现净收益，才主张真实推理提速；否则写清收益边界和否证条件。双方各写本线，再互审对方最强结论。 |

每轮同步只需要一张短表：**从上轮知道了什么、还有哪两个解释无法区分、哪项结果会改变下一轮方向**。由负责人先决定取舍，再让 agent 批量执行；对不会改变结论的参数组合不必补齐。

两条主线合并后覆盖课程项目的主要成果：**B 提供模拟器、基线、负载规律和选点策略；A 提供系统成本、真实恢复机制、优化尝试和实测；两人合并统一图表、适用边界和研究报告。** 不额外设跑数岗，远端扩展也不形成第三条主线。
