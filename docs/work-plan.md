# 双人研究分工

| 研究线 | 责任与成果 |
| --- | --- |
| 真实推理与成本（A） | 复核精确恢复，区分排队、读盘、上传和续算，提供成本范围及无法分离的项。比较同预算下的驻留续算与按需恢复，报告目标首 token 和整组完工。 |
| 跨负载与选点（B） | 维护事件模拟、回放和反例，给出策略在留出负载中的绝对收益、离线最优接近率及尾部代价。向实测线提供能区分机制的正、反例。 |

共同固定候选与强基线，分别报告模拟、实测和外推。只有真实服务对强基线出现净收益，才主张真实推理提速；远程资源只复核代表性案例。
