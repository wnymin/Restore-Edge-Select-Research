# R07-A05 同平均到达率对照的队列压力复算

使用已校验的百炼原始轨迹逐请求复跑。每个请求到达时，统计更早排入且尚未完成的请求数，包含正在服务的请求。同一时刻完成的请求已释放位置。同一时刻到达的请求沿用回放顺序。按逐请求 local-cost 基线测量压力，使比较独立于 entry-replay 的后续选点。另报告基线从到达至成为队首的平均等待。

216 个实验臂的请求顺序与长度、到达时刻哈希、基线精确均值、冻结策略的边界序列和精确均值均与公开归档匹配。每组先对每个源窗求突发减均匀，再按 18 个源窗平均。六行复用相同的 18 个源窗。所有 108 对的平均未完成请求数均增加。

| 模型载荷 | 成本倍率 | 平均未完成请求数增加 | 基线平均队首等待增加（ms） | 冻结策略离线差距变化（ms） |
| --- | ---: | ---: | ---: | ---: |
| 4B | 12× | 2.128 | 645.465 | 0 |
| 4B | 16× | 2.134 | 646.159 | 0 |
| 交替层代理 | 12× | 2.273 | 857.640 | 0 |
| 交替层代理 | 16× | 2.251 | 857.121 | +0.008639 |
| 27B 架构代理 | 12× | 2.007 | 1391.408 | [−48.202, +48.202] |
| 27B 架构代理 | 16× | 1.981 | 1387.690 | [−55.553, +55.553] |

4B 的 36 对都出现更多积压，冻结策略距离线最优的差距在每对都保持相同。交替层代理的正差只有一个源窗。27B 仍有 5 对无法用现有离线上下界确定差值方向。该结果支持把实际积压与可优化的选点空间分别测量。归档生成脚本和配置的某些历史文件哈希仍未找回。这里验证的是当前版本逐臂重现的行为。

## 复现

从仓库根目录运行，脚本按臂输出 JSONL，包含逐请求的到达积压数组。

```powershell
python -m scripts.data.fetch_bailian
python -m scripts.validation.audit_r07_queue_pressure > r07-queue-pressure.jsonl
```
