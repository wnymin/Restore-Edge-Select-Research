# R03 分工计划：动态因素量化、在线可用性与影响评估

**登记日期：2026-11-19。状态：计划已登记，尚未启动。** R03 承接 R01 动态因素辨别与 R02 固定容量后续状态判据；不改写已验收结论，也不预先宣称任何因素可忽略。先冻结衡量方法，再逐项应用于当前证据源中已知的动态因素，并登记新发现项。

## 研究问题与范围

对每个因素分别评估：(1) 离线全局量化难度：拥有全轨迹、事后真值和完整模拟状态时，因素能否表示成可供推演的连续值或离散组合；(2) 在线衡量难度：当前算法在决策时能否取得并利用，能用到什么程度、明确不能用什么、哪些仍未知；(3) 影响程度：因素变化对边界选择／平局的敏感度，以及相对冻结基线的性能劣化。

范围以精确检查点语义、Qwen3.5-4B 第一版 CPU 模拟、现有在线算法与 GPU 观测为主。因素全集从 `dynamic-factor-priority.md`、R01 A/B 记录、R02 CPU/GPU 交付、协议及执行器决策状态抽取。所谓“全部已知”只指这些可审计来源及本轮系统盘点，不宣称穷尽真实服务的所有因素。未来未到达信息、事后标签只作离线评价，不得作为在线输入。

## 衡量方法（由 R03-MET-01 冻结）

### 离线量化难度 Q

- **Q0 完全量化／容易：** 在声明适用域内可从离线状态确定表示；连续量、区间、事件类别、对象身份／顺序等离散结构均可，单位和时点语义清楚，可进入反事实推演。
- **Q1 部分量化／中等：** 只有部分状态、代理、区间或工况可表示；缺失维度／误差明确，能支持部分案例分析但不能普遍精确推演。
- **Q2 暂无可用量化办法／困难：** 即使有全局离线资料也无法形成可操作表示，或合理表示导致结论不可辨识；须指出数据、定义或识别障碍。“尚未做”不能直接评为 Q2。

Q 不计在线采集成本；离散组合不是量化失败。

### 在线衡量难度 O（有序等级）

逐因素、按当前算法与决策时点评分：**O0** 直接可得且完整利用；**O1** 可得但仅部分利用或存在已知粒度／开销限制；**O2** 仅代理、区间或特定工况可用，关键部分不能利用；**O3** 当前无可用决策前观测或算法路径；**OU** 证据不足，暂不能定级。数值越高越难。另记信号来源、最早可用时点、采集／决策开销（未测须标未知）、已利用部分、明确不可利用部分和未知项；OU 不可强判为 O3。

### 影响指标 I

使用同输入、同快照、同候选、同成本、同执行器的配对干预，基准水平和扰动水平预先登记，设计／留出分开：

- **决策敏感度 D：** 边界改变配对比例；另报排序、平局、合法动作改变，样本分母及不确定区间。不能将其称作生产发生率。
- **基线劣化 L：** 相对冻结基线的平均响应差（ms 与比例）、P95、最大单请求退化，以及省略该因素后的闭环净差；明确正负方向。与离线最优的差单列，最优未认证时给区间。

D 与 L 分开报告，不揉成未经校准的总分。优先级先按影响（D/L）×可评估难度（Q/O）二维呈现；若要总排序，报告权重敏感性，不预设权重或统一损失门槛。覆盖普通、容量临界、同刻及邻域、共享／在途与近似平局，并检查因素组合及留出；单因素结果不证明交互安全。

## 因素清单起始范围

逐项登记 Q/O/D/L：候选依赖与合法性；决策时可见请求、顺序和队首；净新增预留／剩余额度；共享身份与去重；释放、交接与重试时机；就绪状态、在途对象身份及搬运次序；运行计算余量；在途传输残余／有效就绪延迟；可覆盖搬运量／消费窗口；搬运、复制、重算成本差与成本误差；同行竞争状态及代理信号；候选近似平局。若属静态配置或信息约束，注明分类理由；拆分因素时注明依据和交互关系。盘点须映射到优先级报告、R01/R02 交付、协议及执行器，不遗漏来源。

## 协作同步协议

R03 按“**一次冻结、一次汇总**”设计，双方不需要频繁同步：

1. **同步点 S0：启动冻结（开始并行前一次）。** 双方确认本计划版本、因素 ID 初始清单、Q/O/D/L 定义、样本分层、基线、留出边界、记录模板和复算入口。S0 后，`R03-INV-01` 可独立完善因素来源映射，`R03-MET-01` 可独立冻结衡量方法；二者完成后以版本化文件作为输入，不要求逐条讨论。
2. **同步点 S1：最终交付汇总（各自完成后一次）。** 协作者提交 `R03-INV-01` 与 `R03-APP-01` 的因素表、证据索引、脚本／命令和未决项；本方提交 `R03-MET-01` 与 `R03-APP-02` 的方法版本和在线评估表。随后由 `R03-INT-01` 按同一版本复核，处理 ID 对齐、冲突和遗漏，生成最终综合矩阵。

因此，正常路径只需两次正式同步：启动时一次、汇总时一次。`R03-APP-01` 与 `R03-APP-02` 在 S0 后可并行，但必须以同一冻结的方法版本和因素 ID 为准；若方法冻结晚于盘点，盘点结果先按 ID 保存，不需要返工全部研究，只需在汇总阶段复核评级。

以下情况才触发额外同步，且只同步最小变更集：因素定义发生拆分／合并、Q/O/D 指标或基线改变、发现影响可行性的硬约束、复算入口失效、证据显示原适用域不成立，或一方被外部状态阻塞。额外同步必须记录日期、变更原因、受影响任务和是否需要重跑留出；不能以临时口头判断替代版本化记录。未经同步批准，不改变共同基线、指标定义、留出边界或因素 ID。
